# Gym-Management-Analytics
Gym Management Analytics

Project Overview

An end-to-end data analytics project focused on analyzing gym operations, membership behavior, class attendance, and revenue using Python, SQL Server, and Power BI.

Technologies

• Python: Data generation, cleaning, exploratory data analysis (EDA), statistical analysis, and data visualization.
• Pandas: Data manipulation and analysis.
• Matplotlib & Seaborn: Data visualization (if used).
• SQL Server: Relational database design, SQL queries, CTEs, views, and business analysis.
• Power BI: Interactive dashboards, DAX measures, KPIs, and business intelligence.

Database Schema

The project includes six tables:

• Members
• Trainers
• Classes
• ClassBookings
• Attendance
• Payments

Key Analysis Areas

• Membership activity and subscription expiration
• Booking completion and attendance patterns
• Class popularity and trainer performance
• Revenue trends and payment methods
• Membership growth and customer behavior

Power BI Dashboard

• Overview: Gym performance KPIs and membership insights.
• Classes: Booking and attendance analysis.
• Payments: Revenue and payment method analysis.

Project Objectives

• Practice data cleaning and exploratory data analysis.
• Design and query a relational database.
• Extract actionable business insights.
• Communicate findings through interactive visualizations.

Data Disclaimer

The project uses synthetic data for educational and portfolio purposes.
